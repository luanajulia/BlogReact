# 🚀 Meu Blog com React & Supabase

Este é um projeto de blog moderno e responsivo desenvolvido com **React** (utilizando Vite para o build) e integrado ao **Supabase** como um Backend-as-a-Service (BaaS) com banco de dados PostgreSQL.

## 💻 Sobre o Projeto

O objetivo deste projeto foi construir uma aplicação de blog funcional, onde os posts são armazenados dinamicamente em um banco de dados relacional. A aplicação consome a API do Supabase em tempo real para listar e exibir os artigos.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

* **React** (com Vite)
* **Supabase** (PostgreSQL, Auth & Storage)
* **JavaScript (ES6+)**
* **CSS3** (ou Tailwind CSS / Styled Components se você usou)
